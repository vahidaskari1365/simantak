# سیمان تک — وب‌سایت شرکتی و ویترین برند

وب‌سایت رسمی **بتن دکور سیمان تک**، تولیدکننده و مجری میکروسمنت، پوشش‌های دکوراتیو و پوشش‌های تخصصی سیمانی.

این پروژه در فاز اول به‌عنوان ویترین برند، معرفی محصولات و خدمات و جذب مشتری طراحی شده و ساختار آن برای توسعه به فروشگاه اینترنتی کامل آماده است. **این نسخه فقط فرانت‌اند است و بدون پایگاه داده اجرا می‌شود.**

---

## ویژگی‌ها

- طراحی مینیمال و حرفه‌ای با هویت بصری برند (قرمز، زرد، سفید و خاکستری گرافیتی)
- کاملاً فارسی و راست‌به‌چپ (RTL) با فونت Vazirmatn
- ریسپانسیو کامل: موبایل، تبلت و دسکتاپ
- تصاویر اختصاصی و محلی در `public/images` (بدون وابستگی به سرور خارجی)
- بهینه‌سازی تصاویر با `next/image` و بارگذاری تدریجی
- سئو: متاداده اختصاصی هر صفحه، Open Graph، `sitemap.xml`، `robots.txt` و داده‌های ساختاریافته (Product، Article، FAQPage، Organization، LocalBusiness)
- مسیرهای استاتیک برای محصولات، خدمات، پروژه‌ها و مقالات

## صفحات

| مسیر | توضیح |
| --- | --- |
| `/` | صفحه اصلی: هیرو، فلسفه برند، آمار، محصولات، خدمات، پروژه‌ها، فرایند، مجله و FAQ |
| `/about` | معرفی شرکت، تاریخچه ۱۳۹۲ تا ۱۴۰۴، توان تولید، آزمایشگاه و مزیت‌های رقابتی |
| `/products` | کاتالوگ محصولات با فیلتر دسته‌بندی |
| `/products/[slug]` | صفحه اختصاصی هر محصول: مشخصات فنی، کاربرد، مزایا، روش اجرا، پالت رنگ و محاسبه‌گر متریال |
| `/services` | معرفی دسته‌بندی‌شده خدمات اجرا |
| `/services/[slug]` | جزئیات هر خدمت: محدوده کار، مراحل اجرا، زمان و نکات فنی |
| `/projects` | گالری پروژه‌ها با فیلتر نوع فضا، کاربرد و متریال |
| `/projects/[slug]` | مطالعه موردی: چالش، راه‌حل، نتیجه و گالری |
| `/journal` | مجله تخصصی با فیلتر موضوعی |
| `/journal/[slug]` | مقاله با فهرست مطالب، جمع‌بندی و محصولات مرتبط |
| `/faq` | سوالات متداول در چهار گروه |
| `/contact` | فرم استعلام قیمت، اطلاعات تماس، ساعات کاری و نقشه |
| `/shop` | پیش‌نمایش فروشگاه با سبد خرید (localStorage) و ثبت سفارش از طریق واتساپ |
| `/admin` | پیش‌نمایش پنل مدیریت محتوا و سفارش‌ها (noindex) |
| `/api/health` | بررسی سلامت سرویس (بدون نیاز به دیتابیس) |

## اجرا

```bash
npm install
npm run dev      # محیط توسعه
npm run build    # ساخت نسخه تولید
npm run start    # اجرای نسخه تولید
```

سپس آدرس [http://localhost:3000](http://localhost:3000) را باز کنید.

## ساختار پروژه

```
public/images/          تصاویر محلی برند، محصولات و پروژه‌ها
src/app/                صفحات و مسیرها (App Router)
src/components/         کامپوننت‌های مشترک رابط کاربری
src/lib/site.ts         اطلاعات برند، تماس و ناوبری
src/lib/content/        محتوای محصولات، خدمات، پروژه‌ها، مقالات و سوالات متداول
src/db/                 زیرساخت Drizzle برای فاز بعدی (در این نسخه استفاده نمی‌شود)
```

برای ویرایش محتوا نیازی به تغییر کامپوننت‌ها نیست؛ کافی است فایل‌های `src/lib/content/*.ts` را به‌روزرسانی کنید.

## فاز بعدی

- اتصال به پایگاه داده (PostgreSQL + Drizzle ORM) برای محصولات، سفارش‌ها و محتوا
- ثبت سفارش و درگاه پرداخت آنلاین
- مدیریت موجودی، قیمت‌گذاری، تخفیف‌ها و اطلاعات مشتریان
- ورود امن به پنل مدیریت و پشتیبان‌گیری خودکار

## فناوری‌ها

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Drizzle ORM (آماده برای فاز بعدی)
